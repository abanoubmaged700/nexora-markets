# Gateway approval and delivery review — 26 October 2026

The AI Studio change at `4f80c9e` reached `main`, but its first publish request wrote caller-supplied `APPROVED` into `trusted_approvals`. A signed request could therefore approve itself. Existing tests printed responses, contacted whatever gateway was listening on port 3001, and made no assertions.

This branch changes the authority boundary. The authenticated reviewer API issues an HMAC approval receipt only after its SQLite approval transaction is persisted. The receipt binds `run_id` and the SHA-256 revision of `outputs`. The local gateway requires the receipt and checks its signature and content hash; request-body approval status and old local `trusted_approvals` records cannot authorize publication. The two signing secrets must be configured privately and separately.

The gateway signs and checks original request bytes, stores an `IN_FLIGHT` run reservation before forwarding, and blocks every later request for that run ID. Legacy idempotency rows without a status migrate to `UNKNOWN` and remain blocked. A network failure, timeout, or downstream error keeps the reservation: delivery may be uncertain, so an operator must reconcile n8n and Telegram before any manual retry. A default n8n HTTP 200 is not a publication receipt; success requires an explicit matching `PUBLISHED` response with a Telegram message ID. Database snapshot writes use a temporary file and rename; a failure before forwarding stops the request.

Verification on this branch: TypeScript, 19 Node test results, and Vite build PASS. The gateway test starts a child gateway with a disposable SQLite database and a local mock downstream; it checks forged approval rejection, changed content rejection, duplicate rejection, 503, concurrency, and legacy migration. It never calls the real n8n instance. Actual n8n response contract, deployment secrets, connection from the cloud app to this Windows gateway, and private Telegram end-to-end delivery remain **NOT TESTED**. Do not expose or activate publishing until those gates pass.
